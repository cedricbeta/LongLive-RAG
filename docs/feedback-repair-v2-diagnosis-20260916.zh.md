# v2 为什么失去原来的修复：第一镜头对账

## 已确认的事实

对齐 v1 与 v2 的 Iris、Clara 第 1 镜头实际渲染配置：随机种子均为 4243、力度均为 1.0。除输入/输出目录路径外，变化集中于重画遮罩和渲染 caption。冻结的生成管线、颜色检查代码和视觉证据比较代码相同。

| 案例 | v1 实际操作 | v2 第一次实际操作 |
| --- | --- | --- |
| Iris | 约 0.579% 画面覆盖；人物外观要求放在 caption 末尾单独一句 | 约 0.597% 覆盖；外观要求合并到开头，原单独强调句消失 |
| Clara | 约 3.800% 画面覆盖；末尾再次明确 `Clara is a middle-aged woman with auburn hair and a long tan coat.` | 约 8.354% 覆盖，约原来的 2.2 倍；删掉末尾再次强调外观的句子 |

覆盖率为 latent 遮罩值不小于 0.35 的单元比例，不能解读为真实头发/衣服覆盖率。Iris 范围变化较小，Clara 变化很大；不能笼统断言两例都失败于范围太大。由于两个因素同时改变，尚未证明范围与措辞各自的影响。

对账数据：`videos/feedback_repair_v2_20260916/analysis/first_shot_actions.json`。

## 三个控制流程问题

### 1. 第一次尝试就替换了原来的操作

v2 让规划者从第一次重画起就自由选择区域并重写整段 caption。实际第一步没有优先尝试原来的区域和描述。增加选项与预览并不保证模型选得更好；这次将原有默认方法也一起换掉，使原版的成功不能自然保留。

修正方向：第一步使用可复现的既有操作，只有本镜头实际失败后再开放有针对性的调整。为定位原因，复现时必须复用归档的准确 mask 张量，不能重新分割后仅凭相近覆盖率就当成同一输入。

### 2. 反馈指出的部位，没有完整连接到可执行区域

Iris 初始检查文字同时指出头发和衣服问题，而 `vetoed_parts` 只包含 `hair`，因为该字段取自像素颜色否决，不包含 VLM 提出的所有衣物形态/种类冲突。规划菜单因此仍只提供头发相关范围。

重画后出现衣服冲突，汇总标签却是 `reject_identity_reference_low_confidence`。`classify_failure` 仅因理由含有 `low_confidence` 就返回 `insufficient_evidence`；循环立即停止。这是已证实的控制流程分支，不能把它归因于视频模型无能力。

修正方向：保留逐部位、逐帧的“符合/冲突/看不清”及证据，先区分明确冲突与判断分歧。衣服问题应触发衣服范围或头发+衣服联合范围；判断分歧应进入有限次复核。不能一概把低置信度当作无缺陷或不可修复，也不能把单个不可靠的 VLM 负票直接升级为必改事实。

### 3. 防重复检查只能挡住坏提案，不能保证替代提案有效

Iris、Clara 多个镜头中，模型面对退回意见仍重复原方案或填错 `revise/resample`，两次提案失败后以 `planner_error` 结束。这是策略拒绝，不是服务崩溃。

修正方向：由程序计算“是否变化、是否重新抽样”和重复预算，不依赖模型给自身动作贴对标签；给模型明确的剩余合法候选。限定重新抽样次数后移除已耗尽候选，保留其他合法范围或单独改变目标描述的路径。仍无可用候选才停止，且未通过的结果不交付为成功。

## 验收也有局限

Iris 原版/v1 的已通过结果，示例帧仍是深色 polo 衫。它的头发有所改善，但不能据通过票数就说“红卷发、苔绿外套全部修好”。新结果暴露的衣服冲突不能靠放宽验收来消失。

因此需要同时记录目标部位是否改善、其他要求是否保持以及哪些仍不确定，避免用一个总票数掩盖局部失败。Clara 的旧改色结果和 Iris 的头发改善可以作为能力线索，不是无条件真值。

## 最小验证顺序

1. 固定 Clara 第 1 镜头的准确原片、已有 mask、种子 4243、力度 1.0、生成代码和验收方式。
2. 比较四组：旧范围+旧描述、新范围+旧描述、旧范围+新描述、新范围+新描述。全部在相同环境重跑，并保留失败结果；归档结果只作参照。
3. 单独用 Iris 的反馈记录测试“有衣服冲突”和“纯粹看不清”能否走不同分支，并检查菜单是否提供对应部位。
4. 恢复可复现的有效操作后，再测试受限规划是否能在失败时提供增益。先避免把第一次尝试交给自由改写整段 caption，也不增加重画预算来掩盖无效策略。

本次是日志、配置与张量对账，没有再次修改修复算法或启动新 GPU 实验。具体哪一种范围/措辞导致生成质量下降，仍需要上述单因素组合实验。
