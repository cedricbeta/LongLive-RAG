## 可执行队列

生成队列继续剩余 33 场景任务，不重新生成已完成场景。

两个评分队列并行运行：

1. **特征队列（GPU 1）**：A → B → 旧 C → 等当前 C 完整生成 → 当前 C。
   每项运行 SC、BC、TF、MS、VTSS、BS、DT 七指标。
2. **模型评分队列（GPU 2 服务，CPU 提取该队列的 DINO 特征）**：固定六例重复 1 → 重复 2 → 重复 3 → A → B → 旧 C → 等当前 C 完整生成 → 当前 C。
   每项运行 CAC、CLC、EG、VLM 四指标。CPU 的局部特征计算避免与 GPU 1 的重指标竞争。

合计 11 个评分作业（4 个特征作业 + 7 个模型评分作业），另有 4 次自动合并，不把合并当作新实验。
具体命令、开始时间、退出码、可观察 fallback 数、等待状态都写入 `campaign.json`。
两部分都成功结束才合并该方法；按完整 11 指标重新计算三组分数与总分，不平均两个局部总分。
合并后自动更新 `comparison.md` / `comparison.json` 和配对 bootstrap 区间。
失败项保留；独立作业仍继续，不能用“部分完成”冒充完整成功。
