# 无需用户看图的固定目标修复初查

用户明确表示无法看图，并要求不依赖人工判断。本轮因此不再声称是人工确认目标的 oracle 实验，也不产生人评标签。

沿用 09-05 的五个候选：ns090 / ns180 / ns190 / ns220 / ns310。助手检查了每例八个 chunk 起始帧、之前生成的 SAM2 遮罩抽帧，记录在 `machine_entity_repair_20260906/target_review.json`。旧图包和人工协议保留不动；新结果写入 `videos/machine_entity_repair_20260906/`。

## 保留的控制条件

- 固定五例，不按修复结果增删；每例一次、同一修复提示词、entry sigma 1.0、实际噪声种子 4243。不添人，不改生成代码，不让原来的自动裁判决定修谁或挑结果。
- 重画前先做无编辑重放，完整解码像素必须与旧 baseline 一致；否则停止该例，先检查混杂因素，不把 baseline 本身的变化算成修复收益。
- 输入／源码指纹检查、独占运行标记和失败日志保留；机器模式必须显式标 `reviewer_kind=assistant`，不能伪装成人工确认。
- 模型检查只报告具体可见的变化。抽帧没有充分证据的动作保真、细小交互或短暂缺陷记为未验证／不确定；不增加颜色阈值、综合评分或假置信度。

## 证据范围

`scripts/prepare_machine_repair_evidence.py` 固定抽取目标镜头的八个 chunk 起始帧，以及每个后续镜头的首帧、中间帧、末帧，保留所有病例和失败。不通过自动评分选择截图。

这轮最多支持“在这几个机器检查的目标上是否出现明确的外观修复收益”。不支持总体成功率、跨镜头身份保持、完整动作保真、独立盲评或最终论文质量结论。由同一助手选目标并看结果，也不是独立评价。

## 状态

五例全部完成一次重画及完整六镜头重放；五例无编辑对照的解码像素全部与存档 baseline 一致。机器模式及相关回归测试共 75 项通过。没有人工确认记录，也没有人评结果。

助手检查了固定抽样的全部 30 张对照图：每例目标镜头八帧、后续五镜头各三帧，修复前后共 230 帧。原始证据见 `videos/machine_entity_repair_20260906/machine_evidence/index.json`，结构化观察见 `machine_entity_repair_20260906/result_review.json`。

## 逐例结果（探索性机器观察，不是成功率）

镜头编号从 0 开始。这里把“指定属性改对”与“整段视频修复成功”分开；没有用自定加权分数合并二者。

| 例子 | 目标镜头可见变化 | 后续镜头可见情况 | 保留的问题 |
|---|---|---|---|
| ns090 / Iris | 黑发、深蓝衣变为偏红发和绿／浅色混合衣；新增白花花盆遮挡面部，人物边缘出现蓝绿色异常 | s1–s5 仍围绕新增花盆，部分帧头部被画面上边裁切 | 不能算干净修复；原先整理散花茎的交互被改写，异常延续到后续 |
| ns180 / Noah | 蓝衬衫变绿；人物尺度、站位、体型与裤子也变化 | s1–s5 绿色衬衫保持；人物开始使用与 baseline 不同的盆／容器 | 指定衣色有收益，但不是只改衣服；姿态、物体和镜头构图未保持 |
| ns190 / Iris | 银白短发变红色卷发，绿色外套与使用电脑的粗粒度动作保留 | s1–s3 红卷发保持；s4–s5 变为较直红发、绿色套头衣，外套不再保持 | 早期发色修复有效，后期仍有属性漂移；Kai 的位置、人物姿态和笔记本交互也改变 |
| ns220 / Clara | 灰衣变浅棕黄外套；两人仍在桌边 | s1–s5 棕黄衣色保持，两人仍在；阅读／递纸的粗粒度交互仍可见 | 起坐时机和纸张数量／位置改变，不能确认细小交互保真 |
| ns310 / Clara | 酒红衣变棕黄外套；右侧 Miles 仍在 | s1–s5 棕黄外套保持，两人继续围绕花瓶 | 头发形状、手部动作、花瓶移动轨迹改变；s4 末抽样帧新增底部文字样伪影 |

四例有清楚的目标属性收益，但这不是“4/5 修复成功”：它们同时包含几何／交互变化和后续漂移。ns090 明显说明，目标选对也不足以保证安全修复。抽样中未看到某类异常，不等于完整视频没有该异常。

## 对下一步的影响

1. 不再增加 locator／颜色阈值等规则来解释这五例；执行器的属性编辑能力已经有正、反两种证据。
2. 完整闭环 benchmark 必须同时报告外观／实体指标、动作与动态程度、后续镜头退化、接受／回退率及计算成本。本轮绕过 guard，不能据此评价正式 H=2 guard 的拦截能力。
3. 先冻结当前方法再比较。若完整闭环无净收益，优先用成对消融检查“修复改了不该改的内容”与“改好的属性未持续”，而不是继续堆放置或定位规则。
4. 这些是首镜头外观违背剧本的案例，不是已证明的跨镜头换人；五例包含事先已知案例，不能替代完整 benchmark 或独立评价。
