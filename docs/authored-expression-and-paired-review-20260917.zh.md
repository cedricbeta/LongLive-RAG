# 脚本绑定表达接入与成对检查器诊断

新增动作已经接入代码；尚无新的验收成功或端到端收益。两次真实 Molmo 探针共调用 39 次，暴露了输出契约和视觉证据问题。全部失败、原始回答、未执行计划与成本均保留。

## 方法改动及真实文件桥接

`run_native_progressive.py --target-expression authored_garment_v1` 是显式选择的新协议。它只在已有失败后提出一句联合服装颜色/类型表达，且必须满足：同一实体恰好两个目标；目标来自当前有效的脚本引文；颜色和服装类型组成的连续短语同时出现在两个来源引文和当前镜头原文中；原始提示词完整保留。已知复数服装、非连续短语、重复属性、其他明确命名角色的混合引文或失效镜头绑定均不产生该选项。它仍依赖编译器对代词和实体的语义归属，文本来源核对并不证明归属正确。

第一动作保持原配方；默认仍为 `literal_clauses_v1`。种子、真实 mask/父分支指纹、力度 1.0、预算、去重、保护和未来验收沿用原控制逻辑。混合证据允许修改仍需单独显式启用。该选项既不把 unknown 改为 pass，也不放宽候选验收。

真实文件桥接从旧反馈运行的初始约束、第一动作和失败路由重建菜单，程序选取唯一合法表达，再调用真实 CPU 原生准备器。v3 重建的提示词、mask、父 latent、种子 4244、12 个资产和 5 个原生源文件与[已有自然表达候选](natural-expression-control-20260917.zh.md)相同，原生动作指纹为 `13e81e51970795f9717e240f84180f436584ff379df4ef59f3ba82e79d2b6db6`。没有再次生成视频，也没有实际 VLM 规划选择或语义验收；不能把桥接成功当作新端到端实验。

v1 在原生准备完成后，核对脚本访问了错误的返回字段并失败。21.014 秒原生准备有记录，完整进程耗时未知，未补造。修正后的 v2 为 22.227 秒 supervisor / 20.366 秒 worker；在加入镜头绑定与编译结果深拷贝后，冻结最终代码的 v3 为 23.335 / 21.653 秒。worker 均嵌套在 supervisor 内。三次原始记录保留；v2 不冒充最终源码。当前导出实现通过 255 项测试和 11 项子测试，绑定 86 个源文件。旧实验继续绑定旧源码快照。

## 两个有明确停止规则的真实 GPU 探针

模型均为固定 Molmo2-O-7B revision `784410650d12be9bc086118fdefa32d2c3bced86`，bf16/SDPA、greedy、每次 seed 0，无语法约束、无解析补救或模型重试。使用同一批预先固定的当前帧 320/352/400/448/479 和后续帧 672/720/768；比较原片、固定第二候选与自然表达候选。GPU 1 执行，GPU 3 未使用。两项协议均预先规定连续三次无效回答或执行失败即停。

| 探针 | 实际调用 / 计划 | 合法回答 | supervisor 秒 | 嵌套 worker / 加载秒 | 设备能耗范围 kJ |
|---|---:|---:|---:|---:|---:|
| 多帧联合检查 | 3 / 12 | 0 | 102.408 | 79.390 / 12.367 | 21.378–21.674 |
| 两图简短服装描述 | 36 / 36 | 36 | 132.966 | 106.984 / 14.507 | 22.354–22.760 |

第一项明确给出固定脚本及目标，要求逐帧四项外观、身份和四类非目标保护字段。连续三次输出不符合契约后停止，剩余九项没有执行。第二次实际调用是相同自然表达序列对照：两侧对应 PNG 完全相同，原始回答却将 A 描述为围裙、B 描述为 moss green coat。即使修复 JSON 也不能消除这个证据矛盾。

第二项改变图像数、提示词、输出字段和 token 上限，只提供两个同时间图像及匿名 A/B 标记，不给脚本目标或分支名。32 次比较覆盖两个比较对象、八个时间点和两个顺序，另有三个真实图像自身对照和一个均匀灰图对照。三个真实自身对照描述一致，但完全相同的灰图被描述为两件不同袖长、颜色的服装。全部 JSON 合法不等于视觉判断可靠，因此不接入验收。两协议同时改变多个因素，不能据此归因于单一图像数或 schema。

查看[全部两图输入及 36 条原始回答](../artifacts/native_iris_paired_reviews/index.html)、[联合检查全部失败](../results/native_iris_paired_review_v1/audit.json)、[机器可读汇总](../results/authored_expression_policy_contracts/paired_summary.json)。交换顺序后的自然语言差异没有自动转成语义不一致率，相关帧也没有当成独立样本。

两次 GPU supervisor 分阶段合计 235.374 秒，不是连续端到端耗时；各自包含权重检查与加载。CPU 准备另为 44.182 秒与 0.099 秒，第一项预处理预检 1.112 秒，桥接成本单列。能耗含设备空闲功耗，不宣称 CUDA kernel 时间。

## 证据边界与下一步

这仍是一个已暴露开发脚本，零真实人工标签，零新生成视频，零新增保留候选。自然表达动作可执行，但身份、动作、非目标和未来保护未获得可靠成对结论。灰图和相同输入控制已足以否定把当前探针直接用作验收器；继续仅凭合法 JSON 放行或无限改提示词没有依据。

下一阶段需要独立于这些开发输出的语义校准证据，再冻结验收与预算协议，进入多脚本/种子、固定重试和冻结选择器对照。匿名真实人工比较、IAMFlow 官方权重访问与适配、必要消融和留出证据仍未完成。当前论文继续标为开发草稿，不满足 submission-ready。
