# 视觉检查输出协议：两个受控开发对照

这两组对照没有解决检查器可靠性问题，也没有改写此前 Iris 候选的回退。生产检查器、生成器、掩码和验收规则保持不变，采用的新协议为零。

上轮真实原生候选的中间帧，衣服种类标签是 `pass`，解释却说不符合 coat 要求。为检查这一具体故障，本轮固定该次运行的全部 7 个属性请求：父视频与候选各三个原始人物裁剪，以及原来那个候选联合复核包。使用同一 Qwen3-VL-8B checkpoint、seed 0、temperature 0、最大输出 2048；每组对照各发出 14 次真实请求，交替 A/B 顺序，每个条件都使用空缓存。禁止传输重试、解析纠正和 schema 回退；所有失败都必须保留。

| 对照 | 唯一变化 | HTTP 请求 | worker 秒 | 26 个属性标签的变化 |
|---|---|---:|---:|---|
| schema 进入消息 | B 在原提示词后追加同一响应 schema | 14 | 344.46 | 25 不变，1 个 fail→pass |
| 先观察后判断 | B 仅重排 schema 字段为 observed/reason/status | 14 | 338.92 | 23 不变，2 个 fail→pass，1 个 pass→fail |

这里的 26 项来自 6 个单帧包各 4 个属性，加联合包的 2 个属性，**不是 26 个独立样本，更不是准确率**。两组使用同一个已暴露脚本的相同裁剪，没有置信区间、显著性或泛化结论。联合包保持原样，即使某个条件在真正的自适应运行中可能选择不同复核范围；本实验不是重新运行整套验收循环。

## schema 文本未解除验收障碍

新 A 条件的 26 个标签全部复现历史标签，但 7 个回答的完整文字均与历史不同。B 的单帧标签完全不变，只有联合复核的衣服颜色由 fail 变为 pass。按原有单帧聚合规则，父视频衣服颜色/种类仍为 fail/fail，候选仍为 unknown/unknown，头发两项保持 pass。

已知的中间帧矛盾在新 A 回答中再次出现：标签为 pass，观察与理由却描述为 dress/jumpsuit、not a coat。B 保留 pass，但把观察改称 coat。解释变得与标签一致，不能据此判定视觉理解正确。

## 输出顺序改变了判断，也留下新的矛盾

字段顺序对照在查看第一组新回答内容前冻结，动机来自历史原始回答总是先输出 status。B 同时重排属性对象的 `properties` 和 `required` 列表顺序；字段、枚举、字数限制和必填集合均保持相同，提示词不添加 schema 文本。后者的顺序也进入缓存指纹，避免仅重排字典后仍碰到规范化哈希相同的问题。每组均有新的原顺序对照，不复用第一组 A 回答。

实际原始回答确认，A 均为 status/observed/reason，B 均为 observed/reason/status。新 A 的 26 个标签仍全部复现历史标签。B 在父视频中间帧把衣服颜色由 fail 改为 pass；在候选末帧把衣服种类由 pass 改为 fail；联合复核的衣服颜色由 fail 改为 pass。单帧聚合中，父视频仍为 fail/fail，候选变为 unknown/fail；这没有产生被接受或被保留的修复。

字段矛盾也未消失：B 的联合衣服种类回答中，`observed` 写 coat，理由却说是 dress/jumpsuit、not a coat，最终 status 为 fail。候选中间帧仍被描述并判为 coat/pass。父视频新增的颜色 pass 也需要独立评估，不能只选择标签向预期方向变化的部分来报告。

## 成本、边界与交付

总计 28 次新视觉请求，两个 worker 合计 683.38 秒，没有新视频、人工标签或候选选择变化。独占服务的启动至退出标记分别为 432.56 和 410.08 秒，包含加载与空闲；这些时间和 worker/请求时间重叠，不能累加当成 kernel GPU 时间。GPU 0 使用后已释放，GPU 3 未使用。

每个新 HTTP 请求的完整字节哈希均由实际输入和冻结字段顺序重新构建并核验；旧请求只保存了消息结构、原提示词和图像哈希，没有原始 HTTP 字节流，因此不声称历史 HTTP 字节完全一致。全部输入裁剪、历史回答、新回答、请求顺序、源码与成本都已保存。[复现说明](../reproduction/native_progressive/VISUAL_CHECKER_PROTOCOLS.md)区分第一组冻结 worker 与后来加入字段顺序选项的共享入口。

当前采用设置仍为零，真实原生试验的 `insufficient_evidence`、原视频选择和零保留不变。下一步需要区分目标属性的时间变化、同图判断冲突和不可见证据，并检查这些状态如何约束后续合法动作；不能把协议造成的标签变化包装成独立质量提升。同预算实验、独立评分和实际人工对比等目标仍未完成。
