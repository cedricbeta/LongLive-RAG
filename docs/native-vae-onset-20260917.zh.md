# 原生 VAE 起始块干预与输入传输核验

本轮排除了两条实现故障解释，但没有证明修复有效：起始帧确实受到了首个编辑 latent 块影响；此前 39 次成对模型请求的输入张量也都能从原始图像精确重建。没有新增扩散采样、VLM 调用或保留候选。

## 冻结的真实解码实验

使用原片和[自然表达候选](natural-expression-control-20260917.zh.md)的真实 bf16 latents、原生 Wan VAE 权重及连续解码代码。两个开关分别决定 `[81,84)` 的首个修复块、`[84,120)` 的后续块来自原片还是候选，组成四个条件。第五次为原片重复对照。每次解码前清空 VAE 缓存，按原生产路径的两个 60-latent 块处理前 120 个 latents，并去掉首个 warm-up 帧，得到 476 帧原始浮点像素。

方案在执行前冻结，预算五次解码、900 秒，无重试。混合 latent 条件仅是因果诊断，并非可交付候选。全部 476 帧数值轨迹、80 张预定 PNG、mask 原始来源与运行日志均保留；PNG 来自 VAE 原始像素，未经过 MP4 有损编码。

| 条件 | 首块来源 | 后续来源 | 相对原片第一个变化的原始帧 |
|---|---|---|---:|
| parent | 原片 | 原片 | 无 |
| early_only | 候选 | 原片 | 320 |
| later_only | 原片 | 候选 | 332 |
| candidate | 候选 | 候选 | 320 |
| parent_repeat | 原片 | 原片 | 无 |

五个条件的前 320 帧完全相同；原片重复的全部 476 帧也完全相同。`early_only` 与候选在帧 320–331 逐像素相同，而 `later_only` 在该范围仍与原片相同。因此，帧 320 的问题不能解释为编辑块直到更晚才影响像素。

在实际自动 mask 的最近邻像素投影内，候选相对原片的平均绝对差从帧 320 的 **0.020837** 增至帧 331 的 **0.256209**，像素取值为 0–1。它是变化幅度，不是服装正确率。首块 mask 有 828/1018/1135 个有效网格单元，三个 latent 的掩码内平均变化为 0.4320/0.6773/0.8328；不是空 mask 或完全未修改的 latent。

[完整数值曲线](../artifacts/native_vae_onset_v1/onset_deltas.png)与[全部预定画面](../artifacts/native_vae_onset_v1/index.html)显示：起始仍为白衫/围裙，随后出现绿色布料，再逐渐形成更明显的外层服装。帧 320/327/331/352 的[事后 mask 边界图](../artifacts/native_vae_onset_v1/mask_coverage.png)可见白衫大部分位于可编辑范围；这不证明边界准确，也不支持“完全漏掉上衣”这一简单解释。没有人工像素标注或 mask 质量评分。

本地对保存的五组原始窗口 `[312,384)` 再计算，共核对 360 帧浮点张量、80 张 PNG 和全部对应差异。张量/PNG 精确相同，浮点统计容差为 1e-8。原始窗口和完整 latents 不进入 Git；远端核验明确只重建已发布摘要、图表和绑定，不能冒充重新执行 VAE。

## 成对模型预处理的独立 CPU 重放

使用原固定 Molmo 处理器、全部 39 次真实请求的提示词、图像顺序和 PNG。在不加载模型权重、不调用语言模型的条件下重新计算文本 token、attention mask、pixel values、image pooling、grid 和 crop counts。**39/39 个完整输入张量字典的形状、dtype 和字节哈希均匹配实际运行记录**。四个双图自身对照的归一化像素块也完全相同，包含此前虚构两套服装的灰图对照。

这排除了本次输入传输错配；不把剩余问题归因于某一个未隔离因素，也不提升这些模型回答的可信度。解析有效率仍不等于视觉准确率。

## 成本与下一步

CPU 准备 0.588 秒；VAE supervisor 322.974 秒，包含 314.953 秒 worker，其中加载 0.717 秒。各条件约 62 秒的记录包含解码、CPU 差异分析和文件输出，不是纯 GPU kernel 时间。NVML 设备能耗范围 76.250–76.535 kJ，包含空闲功耗；未观察到同 GPU 其他计算 PID。GPU 1 执行，GPU 3 未使用。CPU 预处理重放为 5.578 秒，与 VAE 作业部分重叠，不能直接相加成端到端耗时。

下一条可检验假设是：在保留旧服装前缀与检索上下文的条件下，修复倾向于产生逐渐换装，而非立即满足新属性。当前结果尚未隔离“首块 latent 的语义内容”和“解码历史贡献”，更未证明检索是根因。应先检查实际修复的 KV/检索来源，再设计保持权重、提示词、mask、种子一致的有限上下文干预；不能直接关闭整个记忆系统后宣称原方法可插拔有效，也不能丢弃起始帧来获得通过。

本轮不修改生产控制策略、验收或历史零保留结论。可信验收、累计改善、正式多脚本对照、IAMFlow 与真实人工评价仍未完成。[复现入口](../reproduction/native_vae_onset/README.md)包含离线核验与真实解码命令。
