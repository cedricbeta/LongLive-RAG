# Iris：不提供目标要求的跨模型观察诊断

已完成 35 次原生 Molmo2-O-7B 调用，全部符合本次简化输出格式。这里研究的是已有检查器是否把实际衣服类别与脚本要求混淆，不是用新模型替代人工真值或重新批准历史候选。[完整审计](../results/native_iris_molmo_observations_v1/audit.json)与[全部画面和原文页面](../artifacts/native_iris_molmo_observations_v1/index.html)保留所有输入和回答；HTML 下载后可本地查看。

模型是已下载并校验的 `allenai/Molmo2-O-7B@784410650d12be9bc086118fdefa32d2c3bced86`，与控制器的 Qwen3-VL 属于不同家族。其原生用法与模型组成见[官方模型卡](https://huggingface.co/allenai/Molmo2-O-7B/blob/784410650d12be9bc086118fdefa32d2c3bced86/README.md)。此前同模型的复杂身份格式诊断失败仍保留；本次任务与格式不同，不能把两次结果的差异归因于某一个因素。

运行前固定四条已生成视频：原始父分支、两臂共享的第一候选、反馈第二候选、固定噪声第二候选。每条使用导出帧 320/352/400/448/479/672/720/768，前五张覆盖当前 20–30 秒窗口，后三张位于后续 40–50 秒窗口。另有一张同尺寸灰图，以及原片与固定噪声第二候选各一张 25 秒图片的原样复测，固定随机顺序。没有裁剪、人工 mask 或参考身份图。

每次模型只接收一张完整图片和相同的观察提示：描述可见人数、衣服类别/颜色/袖子/层次及头发，并说明不确定之处。模型看不到脚本、预期的 `moss green coat`、分支名称、规划结果或旧标签。使用贪心解码、每次 seed 0、最多 512 个新 token，无 grammar 约束、解析修补或重试。35 次完成不等于 35 个独立样本；本次仍只有一个已暴露脚本。

## 原始回答揭示的有限线索

原片的八个衣服描述，以及反馈第二候选的八个描述，都含有 `apron`。共享第一候选和固定重试第二候选各有三条衣服描述含有该词，其他回答出现 shirt 或 dress。32 条衣服描述均未出现 `coat`。[事后文字清点](../results/native_iris_molmo_observations_v1/description_inventory.json)只按字符串计数，不将词频转成缺陷率、服装分类真值或方法排名。

这些观察与“围裙未变成所需外套”的失败线索一致，但模型仍不可靠。例如固定第二候选的 25 秒画面被描述为 `Long-sleeved shirt with a zipper`，实际展示帧的袖长并不支持这一描述；多条不确定性还重复无关的性别问题。这是开发者对照图片的检查，不是受试者标注。不能因为全部 JSON 合法就采用该模型作为验收器，不能仅靠未出现某个词判定目标一定失败。

灰图报告零人物。两次同图复测均重现相同的预处理张量哈希、生成 token 和文字回答。这验证本次输入及解码的可重复性，没有校准真实图片的语义准确率或身份判断。当前所有候选仍不保留，原片交付结论不变；本次后续图片观察也不是此前生产流程已执行未来验收的证据。

## 成本与复现

supervisor 为 109.427 秒，worker 为 84.126 秒，其中模型加载 15.085 秒；这些是嵌套区间，不能相加。GPU 1 的只读 NVML 观察给出 16.095–16.410 kJ 设备能耗区间，54 个区间内采样，无查询错误或观测到的外部计算 PID。设备能耗包含空闲，利用率积分不是 kernel GPU 时间。初次 observer 因基础环境缺少 `pynvml` 而在模型启动前退出，日志保留；随后使用已有 SGLang 环境的 observer，模型执行环境没有改变。

离线复核重建全部 32 个实际视频帧，核对每次输入图、回答、生成设置、源码、模型清单及 telemetry，并逐字节重现审计 JSON。[复现命令](../reproduction/native_observations/README.md)同时提供真实调用和无模型审计。权重不随 Git 发布，已有官方 LFS 校验记录可追溯。本次新增生成视频数为 0，真实人工标签为 0。

## 下一项受控修改及排除的解释

检查采样包含帧 320，但时间映射为 latent 81 → 导出帧 320–323，实际编辑区为 [81,121)。因此“第一张图片仅属于保留前缀”的简单坐标错位解释不成立，不能删掉这张失败证据。该映射核对不等于测量了 VAE 的逐帧因果影响或衣服是否即时改变。

基于实际重复的衣服类别问题，另冻结一次自然表达对照：在固定第二候选的原提示后追加 `Iris wears a moss green coat.`，逐字属性由原自动编译脚本产生。保留同一父视频/latent、自动 mask、seed 4244、力度 1.0、编辑区、权重与原生重放代码，仅改变实际提示词。它是已结束两臂实验之外的一次后续开发试验，不补算成原等预算对照的新结果；候选不得仅凭本次稀疏观察被接受。[准备入口](../implementation/scripts/prepare_native_expression_control.py)会核对实际动作仅有提示词哈希不同。该新生成及十次后续观察现已完成：[独立记录与完整视频](natural-expression-control-20260917.zh.md)。中后段服装形态改变，但开头围裙未消失，尚未执行成对验收或保留。
