# 擦除区域:VLM 指框 vs CLIPSeg 文字分割(2026-09-02)

问题来源:08-26 组会里修复环的三个观察——mask 不准、重绘对不齐、VLM 复核看不懂。
用户提议"擦除区域能不能让 VLM 来做"。这份笔记回答这个问题,顺带把修复环
真正的瓶颈定位出来。所有产物在 `docs/mask_method_comparison_20260902/`。

## 结论先写

四种 mask 方法在 12 个漂移镜头上的修复效果没有区别:身份指标各涨 0.02–0.04,
裁判复核通过率都是 6/12。成功的镜头四种方法一起成功,失败的一起失败。擦除区域
的几何精度不是瓶颈;瓶颈是"该擦谁"这个语义判断,而这一步由 8B 裁判决定,
它在多人场景下经常判错。让 VLM 直接指框(M3)不但没有更好,几何上还更碎。

## 实验设计

场景:arm C v4 pilot 的三个 NarraStream 场景(ns000 图书馆 / ns100 讲堂 /
ns190 酒店大堂),今天重新渲染 baseline(原因见"运维教训")。裁判用 pilot
原 prompt 对 shot 1–5 判漂移,15 个镜头里判出 12 个,全部进入测试集。

四种擦除区域,同一个修复 prompt(caption + 裁判写的参考描述)、σ=1.0、同噪声种子,
只换 mask:

| 方法 | 谁决定擦什么 | 谁画出区域 |
|---|---|---|
| M0 recorded | 裁判自由文本 `repaint_region`(pilot 现状) | CLIPSeg |
| M1 short | 裁判受限输出 1–3 个短名词短语 | CLIPSeg 取并集 |
| M2 box_sam2 | 同 M1 的短语 | Qwen3-VL 逐 chunk 出框 → SAM2 传播 8 帧 |
| M3 box_direct | Qwen3-VL 看参考帧 + 当前帧 + 漂移描述,直接指"该擦的区域" | SAM2 |

Qwen3-VL-8B 的框坐标是 0–1000 归一化(`qwen3vl_bbox_calibration.png`,绿框正确),
不是像素坐标。

评测:DINO 身份相似度(主体裁剪 vs shot 0 参考质心)、裁判复核(同一 8B 模型)、
渲染前置帧 MAE=0 的确定性检查(全部通过)。

## 肉眼看到的东西

三类现象,每一类都和 mask 方法无关。

**该擦谁判错了。** ns100 shot 2、3 里 Noah 变成了第二个女人,裁判给的目标词
是 "man",画面里已经没有男人,M1/M2 覆盖率为零,等于没修;M0 给的 "person" 把
合法在场的 Iris 也擦了;M3 指框指到左边的女人但只盖住一半。ns190 shot 1 里
Kai 按剧本进场,M0 的裁判却把目标写成 "man",把 Kai 擦了。ns100 shot 1 里
四种方法都把本来没错的 Noah 擦掉,M1 直接擦成空座位,裁判复核居然通过。

**裁判前后不一致。** ns100 shot 2、3 的 M1/M2 mask 为零,渲染结果和基线逐像素
相同,第一轮判"漂移"、复核判"通过"。同一段画面两次判决相反,只是 prompt 措辞
略有不同。这条直接解释了组会上"人眼觉得没修好但 VLM 放行"的观察。

**修复本身失败,与 mask 无关。** ns000 shot 4、5 里男人衣服上多出的大 logo,
四种 mask 都把人整个盖住、满噪声重画,logo 还是回来了——历史 KV 里带着 logo,
重画时被读回来。ns100 shot 4 里 Noah 根本不在画面里,擦空座位画不出他。
这两类对应修复报告里的分型 b(带宽)和 c(先验缺失),换 mask 无解。

M3 的几何质量最差(帧间 IoU 最低,经常只盖住半个人,或者框到沙发),8B 模型
在"对比参考帧再定位"这种复合任务上不可靠;M2 的纯定位(给短语出框 → SAM2)
几何上最干净,但目标词错它就跟着错。

## 对修复环的含义

1. 不值得在 mask 几何上投入。CLIPSeg 够用;要更紧的边界用"短语 → 框 → SAM2"。
2. 要改的是目标选择的形态:先用 grounding 把画面里所有人框出来(这一步 8B 很稳),
   再逐人裁剪问裁判"这是参考人物 / 剧本叫来的人 / 多余的人",擦掉后两类之外的
   漂移者和多余者。不再让裁判用一句话命名目标。
3. 参考描述在 shot 0 冻结(裁判这次把 ns190 的 Iris 描述成白发,因为 baseline
   shot 0 本身就渲成了白发,而剧本写的是红卷发——参考应该来自剧本而不是画面)。
4. 复核裁判需要校准集和硬守卫:主体人数不能少于剧本 cast,主体消失不能通过。
5. logo 回流说明满噪声 mask 重画敌不过历史 KV 里的漂移内容,这是写入路线要正面
   处理的机理问题:重画时应把带漂移的历史块隔离出上下文,或配合 V-edit。

## 追加:按实体定位的可行性测试(同日)

组会后的改法是把"该擦谁"换成"剧本里的每个实体现在在哪"。先不渲染,只测定位:
对 3 个场景、shot 1–5、每个 chunk 首帧、每个剧本实体,给 8B 模型参考裁剪图 +
剧本描述,问"这个实体在这一帧的哪里,外观变了也要找,不在就说不在"。SAM2 把框
传播成轨迹。结果在 `locate_table.json`、`locate_overlays/`。

| 情况 | 行数 | 结果 |
|---|---|---|
| 剧本说在场 | 19 | 80% 的 chunk 找到;框和 person 框的 IoU 0.85;相邻 chunk 框稳定度 0.80 |
| 剧本说不在场 | 6 | 21% 的 chunk 报"在",但逐条看都是画面里确实有(ns100 shot 3 的 Iris) |

能用的部分:实体在场且大致像本人时,定位又紧又稳,Kai 进场从第 2 个 chunk 起
被稳定跟住,Kai 离场后 3 个镜头全部正确报"不在"。

不能用的部分:ns100 shot 2、3 里 Noah 被换成女人,模型对 Noah 全部报"不在",
不会把"顶替他位置的人"当成他。这恰好是最难的漂移类型,也是 mask 最重要的场景。
另外在场实体有 20% 的 chunk 漏检(ns190 shot 1 的 Iris 中间两个 chunk 没找到),
逐 chunk 独立定位不如在整个镜头上用 SAM2 从找到的 chunk 向两边传播。

所以按实体定位这一步要补两件事才完整,两件都不针对"人":(1) SAM2 在镜头级传播,
补漏检;(2) 多一个通用原语"列出这一帧的所有主体",减去已分配给实体的轨迹,剩下的
就是"没人认领的主体",替身就落在这里。有了它,"Noah 不在 + 一个没人认领的主体"
这个数据状态自然导出"擦掉替身、按 Noah 的描述重画",不需要规则。

## 追加:实体裁判 + 多轮修复闭环,三场景首跑(同日)

按组会后定下的形态实现并跑通(代码:`utils/agent_entity_judge.py`,运行时多轮改动在
`utils/agent_runtime.py`,demo 接线 `scripts/run_agent_edit_demo.py --judge entity`,
实体表 `example/narrastream_bench/entity_specs_pilot3.json`;产物在 `entity_loop/`)。

裁判只问三个问题:每个剧本实体在哪(参考裁剪 + 描述 → 框 → SAM2 镜头级轨迹)、
这一帧有哪些主体(无类别枚举,按分割结果归属,没归属的即"无人认领")、每个实体
像不像参考。判决从这三个答案的集合关系导出:全部在场且像 → 接受;有实体不像 →
mask 是它的轨迹;有实体缺席且有无人认领主体 → mask 是那个主体的轨迹、prompt 写
缺席实体的剧本描述;缺席且没有替身 → 没有 mask,走重采样。无人认领主体只在有
实体缺席时才算数(否则书立、路人都会被当成替身,首跑时就撞上了这个坑)。修复
最多 3 轮,每轮换种子、mask 按复核结果收缩,全拒时取 `repair_score` 最高的一轮
隔离提交。

首跑结果(同一天、同一编译周期内渲染,编辑前帧与 baseline MAE 0):

| 场景 | 修复 | 隔离 | 身份相似度(shot 1–5 均值,对 shot 0 参考) |
|---|---|---|---|
| ns000 图书馆 | 0 次,6 镜头全接受 | 0 | 0.799 → 0.799 |
| ns100 讲堂 | shot 2 一轮修复通过(替身女人 → Noah 回来) | 0 | 0.694 → 0.749 |
| ns190 酒店 | shot 0 一轮修复通过(白发 → 剧本的红卷发) | 0 | 0.641 → 0.683 |

肉眼(`final_*.png`,上 baseline 下交付):ns100 的 shot 2、3 里 Noah 回到了 Iris
身边,后续镜头是他一个人;ns190 的 shot 0 修复后,红发 Iris 一路保持到 shot 5,
因为后面的镜头是从修好的历史生成的——蝴蝶效应这次站在我们这边。对照 pilot v4
的旧裁判:同样三个场景,12 次修复全部被复核打回、全部隔离。

还没解决、要写进下一轮预注册的:(1) 在场判定现在只要求任一 chunk 定位到
(ns100 shot 4 只在前两个 chunk 找到 Noah 也算在场);(2) ns100 shot 5 交付帧右缘
有一个多余人影,实体齐全时多余主体按设计不管,这条边界要不要收紧看 benchmark
指标;(3) 同种子渲染在编译周期之间不逐位一致(今天早上和中午又差了一次),
每次实验只能在同一周期内自比;(4) 只跑了 3 个场景一个种子,没有校准集,
接受率 100% 有可能是裁判偏宽,要用人工标注核。

## 追加:33 场景首批隔离里的一个机理案例(ns010 shot 4)

`entity_loop/ns010_shot4_history_wins.png`(左:Iris 参考裁剪;右四格:baseline 与三轮
修复的 shot 4 中间帧)、`entity_loop/ns010_shot4_mask.png`(第一轮的 mask 叠加)。

剧本:shot 1–3 Iris 和 Kai 同框,shot 4 Iris 独自放回旧书。baseline 的 shot 4 里
Iris 的位置站着一个灰外套、戴耳机的人物,像 Kai 和 Iris 的混合。裁判判"Iris 缺席
+ 一个无人认领主体",mask 把这个人物从头到脚完整盖住(覆盖率 0.16–0.21),prompt
是 caption 加"Iris is a middle-aged woman with curly red hair and a moss green coat"。
三轮满噪声重画、三个不同种子,画出来的都是同一个灰外套人物、同一姿势。五个候选
的 repair_score 全是 −1,按设计隔离交付。

这不是 mask 的问题,也不是种子运气:mask 内完全重画时,模型读的是历史 KV,而
历史里最近三个镜头在这个位置附近都有 Kai,所以重画出来还是他。之前 08-20 报告里
"传播半衰期 1–2 块"和这次 ns000 logo 回流都是同一件事的侧面,这次是干净的复现:
mask 已验证盖全、三个种子一致。结论:masked renoise 只能改写"没有历史支撑"的
漂移;当历史 KV 在同一位置存着另一个角色时,写入路线需要连历史一起处理——
重画时把含该角色的历史块隔离出上下文,或用 V-edit 直接改写历史里的值。这条要进
下一轮预注册。
