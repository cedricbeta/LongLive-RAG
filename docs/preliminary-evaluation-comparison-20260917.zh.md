# 初步评测对比：历史本地 5B 原片与修复版

本表整理已有逐脚本结果，无新增生成或评测调用。对照为本地 Wan2.2-TI2V-5B 原生 baseline 与 2026-09-11 修复实现（评分于 9 月 13 日完成）；33 个已暴露开发脚本，每条 16 秒、单生成种子，采用 NarraStream 指标及 Qwen3-VL-8B 开发评估。不是官方 LongLive-RAG/IAMFlow 的成对实验，也不是播放页五个精选案例的评分。

全部分数乘以 100，越高越好；变化为修复版减原片。按 sample_id 核对全部 33 条脚本及提示词一致，并从逐脚本分数重算均值；未使用仅含部分指标的 total_score。

区间在脚本层进行 10,000 次成对 percentile bootstrap，随机种子 20260917。它们只反映这一批单种子脚本的重采样波动；未校正多重比较，未覆盖共享叙事模板、跨生成种子或裁判重复打分的全部不确定性。EG 仍有解析回落/重复打分噪声，历史局限见 [原分析](../docs/benchmark-fixes-20260911.zh.md)。

实体属性和指令分数的均值略升，运动平滑度、抗闪烁等部分均值下降；本批结果尚不支持整体质量稳定改善。所有指标完整保留，不能把单项名义区间当成正式验证结论。
