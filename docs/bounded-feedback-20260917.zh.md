# 受限反馈实现与官方动作接口

本轮补的是方法实现和真实产物上的动作接口，不是新的视频效果结果。官方 Iris 上一轮仍为零保留；本轮没有新视频生成、视觉模型调用、人工标注或独立评分。

## 固定首轮与有限动作

本地 5B 渐进执行器新增显式选项 `--repair_policy progressive_feedback`。首次使用既有固定配方。之后模型只返回合法动作编号或 stop，程序负责真实动作身份、重复与预算；不再要求模型正确填写 revise/resample，也不允许它自由重写场景和动作。

| 结构化失败 | 可用动作 |
|---|---|
| 目标未改善 | 原配方的一次新噪声；追加原脚本属性；已有更大区域 |
| 明确范围不足 | 程序证明为更大范围的选项 |
| 保护内容或后续退化 | 程序证明为更小范围的选项 |
| 证据不足、评测错误 | 停止新增渲染，保持未解决 |

范围不足这个类别由接口支持；当前控制器没有新增一个能可靠识别 mask 漏检的模型。目标仍失败时，更大区域和属性强调只是可验证的假设，不能当成已确认根因。每个选项相对固定配方只改变范围或提示词；从两个不同选项之间切换，可能同时撤销前一次提示变化并换范围，日志保留实际输入，不能宣称每两个相邻尝试都是单因素比较。

动作指纹绑定当前父视频、父 latent、实际 mask 张量及时间坐标、实际提示词和 seed。仅改路径或说明不能得到新动作；相同动作族最多一次新噪声重试。已耗尽的选项先从菜单中删除。提示变化只在保留原始提示词的末尾追加已存在的固定脚本值，不能引入年龄、身材等隐藏属性。力度固定 1.0。

## 部分保留与预算

新模式沿用现有当前最好分支、固定原始参照和隔离身份记忆。保留部分改善后，在新的父画面上重新构造区域；旧父版本 mask 的来源校验必须失败。失败子分支不会成为下一轮父版本。规划完成后再次核对实际输入，防止模型调用期间文件变化。预算从本镜头初始诊断和定位之前开始计时，并在规划后、启动渲染前再次检查。服务启动、其它镜头及外部调度成本仍需单独计入完整实验成本。

现有逐属性检查器有一次有上限的视觉复核；本轮没有声称实现新的补帧、脸部放大或身份复核循环。历史检查器的类别、角色绑定和保护失败仍然存在，不能因新增规划模块就假定验收可靠。

导出的[测试记录](../results/bounded_feedback_contracts/exported_tests.txt)覆盖首轮不调用规划者、只换噪声的识别、耗尽动作移除、错误编号的有限纠正、父/坐标绑定、部分保留后继续修复、未知保护时停止、规划期间输入变化及规划耗时耗尽预算。测试使用合成执行器和判断，不能代替视频效果实验。

## 官方生成器的真实产物校验

在原官方 Iris 父视频上，仅改变 clothing 的阈值为 0.25、0.35、0.45，人物与 face 阈值均保持 0.35，所有坐标仍由程序产生。CPU 处理耗时 274.0372 秒。三个 mask 的平均覆盖分别为 20.5008%、18.3321%、14.7909%；全张量验证表明它们分别为默认范围的严格超集、相同集合和严格子集。0.35 默认张量与上一轮 mask 逐位相同。这些集合关系不证明语义定位正确或身份安全。[原始 mask 记录](../results/official_iris_feedback_regions/result.json)保留参数、全部 40 个时间位置及来源哈希。

新增官方[动作接口](../adapters/official_longlive_rag/feedback_bridge.py)把合法选择交给现有原生准备器，检查同一官方 revision、12 项模型/初始化资源和实际执行输入。首轮 native action fingerprint 仍为 `6d0507bdcfc37b380374d2bcdca0e84c4a92d49fdcb2adfdb9d48693ce3fe812`，证明没有替换既有首轮操作。对真实 Iris 的不足证据状态，后续菜单为空，不触发重新抽样。

[最终接口检查](../results/official_feedback_bridge_final_probe/result.json)还在同一真实区域上检查各类**假设失败标签**的菜单。这些标签不是新观察到的结果，不能作为自适应修复成功率。早期两份接口检查也保留：第二份加入反馈与父版本/动作的强绑定，最终份增加目标失败时的更大区域假设。

完整官方渐进闭环、真实反馈选择及生成对照尚未完成；当前官方接口仅负责动作准备，不管理候选验收和父分支提交。下一步需要完成该接入，再在开发数据上验证实际净收益与预算，随后才能冻结正式实验。不能用本轮程序测试或假设菜单替代固定重试、best-of-N、独立评价和真实人工评价。入口见[复现说明](../reproduction/bounded_feedback/README.md)。
